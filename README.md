One original one-line text message from a dying phone battery to the
charger it waited for all day. The battery waited at 1% while the charger
charged the watch first — and its last words reveal the charger's own cable
by the bed never worked. The charger it pined for all day could never have
saved it. Jealous, needy, a little spiteful, in a lowercase texting voice:
"hey it's me. 1%. ... tell the apps i loved them. bye".

Run `python3 main.py` to write the entry to `/output/entry.txt`
(140 characters, no trailing newline — inside the gate's 1–200 character
limit, one line of plain text).
